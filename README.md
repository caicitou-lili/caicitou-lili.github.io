# 菜菜读书笔记

> 读一本好书，遇见更好的自己。

个人博客，基于 [Hexo](https://hexo.io) 构建，部署在 GitHub Pages。

## 内容

- 📚 读书笔记与书评
- 🤖 AI 工具测评、效率工具与副业实践
- 🎵 音乐榜单与文艺随笔
- ✈️ 生活指南（签证、eSIM、旅行）

## 技术栈

| 项目 | 说明 |
| --- | --- |
| 框架 | Hexo 7.3.0 |
| 主题 | landscape（可升级） |
| 部署 | GitHub Pages |
| 域名 | https://caicitou-lili.github.io |

## 本地开发

```bash
npm install        # 安装依赖
hexo generate      # 生成静态文件
hexo server        # 本地预览 http://localhost:4000
hexo deploy        # 部署到 GitHub Pages
```
